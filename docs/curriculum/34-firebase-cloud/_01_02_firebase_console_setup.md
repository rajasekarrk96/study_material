# Firebase Console Setup

> **Course**: Firebase | **Module**: Firebase Introduction | **Difficulty**: beginner

---

Setting up Firebase project console, enabling database services, and generating API keys for IoT integration.

---



---

The Firebase Console is the web portal for managing project resources, database rules, authentication providers, and service accounts.

---

Firebase Config Object:
apiKey, authDomain, databaseURL, projectId, storageBucket, messagingSenderId, appId

---

### ESP32 Firebase Client Configuration Struct

```cpp
#include <FirebaseESP32.h>
#define FIREBASE_HOST "my-project.firebaseio.com"
#define FIREBASE_AUTH "secret_api_key"
```

---

Leaving default security rules open to read/write for all users.

---

**Q1: Where do you find the Firebase web configuration parameters?**
A: Project Settings -> General -> My Apps -> Web App.
