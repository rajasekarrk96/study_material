# Computer Fundamentals — Master Syllabus

**Target Role:** Software Engineer / Systems Developer / Embedded Developer  
**Difficulty Level:** Beginner  
**Estimated Duration:** 40 Hours  
**Prerequisites:** None  
**Required Courses:** None  
**Optional Courses:** None  

---

## Study Flow

### 1. Computer Fundamentals

#### 1.1. Module 1 — Architecture & Digital Logic

1. **CPU Architecture & Von Neumann Model**
    - ALU, Control Unit, and Registers
    - Von Neumann Architecture vs Harvard Architecture
    - The Instruction Cycle: Fetch, Decode, Execute, Store
    - Memory Registers: PC, IR, MAR, MDR
2. **Number Systems & Binary Data Representation**
    - Binary, Octal, Decimal, and Hexadecimal Conversions
    - Two's Complement for Signed Integers
    - IEEE 754 Floating-Point Standard
    - ASCII, UTF-8, and Unicode Character Encoding
3. **Memory Hierarchy & Storage Technology**
    - Registers, L1/L2/L3 Cache, RAM, and Secondary Storage
    - SRAM vs DRAM Mechanisms
    - Virtual Memory, Paging, and Memory Management Units (MMU)
    - Storage Protocols: NVMe, SATA, Flash Memory

#### 1.2. Module 2 — Operating System Fundamentals & Process Management

1. **Operating System Architecture & Kernel**
    - Kernel vs User Mode (Ring 0 vs Ring 3)
    - Monolithic vs Microkernel Architectures
    - System Calls and Interrupt Vectors
    - Process Management and Process Control Blocks (PCB)
2. **Concurrency, Threads & Synchronization**
    - Processes vs Threads
    - Context Switching Overhead
    - Race Conditions, Mutexes, and Semaphores
    - Deadlocks: Prevention, Avoidance (Banker's Algorithm), and Detection

#### 1.3. Module 3 — Data Structures & Systems Programming Foundations

1. **Data Representation in RAM**
    - Pointers, Memory Addresses, and Endianness (Little vs Big Endian)
    - Stack Allocation vs Heap Allocation
    - Buffer Overflows and Memory Corruption
    - Garbage Collection vs Manual Memory Allocation
