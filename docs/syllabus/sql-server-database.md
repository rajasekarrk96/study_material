# SQL Server Enterprise Database Architecture — Master Syllabus

**Target Role:** SQL Server DBA / Database Engineer / Enterprise Backend Developer  
**Difficulty Level:** Intermediate  
**Estimated Duration:** 70 Hours  
**Prerequisites:** database-technologies  
**Required Courses:** mysql  
**Optional Courses:** dotnet-full-stack  

---

## Study Flow

### 1. SQL Server Administration & T-SQL

#### 1.1. Module 1 — T-SQL & Database Architecture
1. **Advanced T-SQL Programming**
    - DDL, DML, Complex Joins, and Subqueries
    - Stored Procedures, User-Defined Functions (UDF), and Triggers
    - Common Table Expressions (CTE) and Window Functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`)
2. **SQL Server Storage & Indexing Engine**
    - Pages, Extents, Allocation Maps, and MDF / LDF Files
    - Clustered vs Non-Clustered Indexes, Columnstore Indexes
    - Index Fragmentation, Maintenance Plans, and Rebuild / Reorganize

#### 1.2. Module 2 — Performance Tuning & High Availability
1. **Performance Diagnostics & Query Optimization**
    - Execution Plan Analysis: Scans vs Seeks, Key Lookups, Spills
    - Query Store, Dynamic Management Views (DMVs), and SQL Server Profiler
    - Deadlock Graph Analysis and Transaction Isolation Levels
2. **High Availability & Disaster Recovery (HADR)**
    - Database Backups (Full, Differential, Transaction Log) & Point-in-Time Recovery
    - AlwaysOn Availability Groups (AG), Log Shipping, and Database Mirroring
