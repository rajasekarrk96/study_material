# .NET Full Stack Engineering — Master Syllabus

**Target Role:** .NET Full Stack Developer / C# Solutions Architect  
**Difficulty Level:** Advanced  
**Estimated Duration:** 300 Hours  
**Prerequisites:** computer-fundamentals, networking-fundamentals  
**Required Courses:** c-programming, mysql  
**Optional Courses:** react, docker, aws  

---

## Study Flow

### 1. C# & .NET Core Foundations

#### 1.1. Module 1 — Modern C# Language Mastery (C# 12 / 13)
1. **C# Fundamentals & Memory Management**
    - Value Types vs Reference Types, Stack vs Heap
    - Nullable Reference Types and Pattern Matching
    - Memory Management: Garbage Collector (GC), Span<T>, and Memory<T>
    - Async / Await Task-Based Asynchronous Pattern (TAP)
2. **Generics, Collections & LINQ**
    - Custom Generic Classes and Interfaces
    - LINQ to Objects, Expression Trees, and Performance Optimization
    - Delegates, Events, Func<T>, and Action<T>

#### 1.2. Module 2 — ASP.NET Core Web API (.NET 8 / 9)
1. **API Architecture & Middleware Pipeline**
    - Kestrel Web Server & Program.cs Setup
    - Dependency Injection (Transient, Scoped, Singleton)
    - Middleware Construction & Global Exception Handling Filters
    - Request Routing, DTOs, and FluentValidation
2. **Data Access with Entity Framework Core (EF Core)**
    - DbContext Configuration & Code-First Migrations
    - LINQ to Entities: Lazy Loading vs Eager Loading vs Explicit Loading
    - EF Core Interceptors, Change Tracker, and Raw SQL Execution

#### 1.3. Module 3 — Real-Time Systems, Microservices & Frontend Integration
1. **ASP.NET Core Security & Microservices**
    - Authentication & Authorization: JWT, ASP.NET Core Identity, OAuth2
    - Real-Time Communication with SignalR
    - Microservices Integration with gRPC and MassTransit (RabbitMQ)
2. **Modern Frontend Integration (Blazor & React)**
    - Single Page Application (SPA) Hosting in ASP.NET Core
    - Blazor Server vs Blazor WebAssembly
    - Production Containerization with Docker & Azure App Services
