# Python Selenium Test Automation — Master Syllabus

**Target Role:** QA Automation Engineer / SDET (Python)  
**Difficulty Level:** Intermediate  
**Estimated Duration:** 60 Hours  
**Prerequisites:** core-python  
**Required Courses:** core-python  
**Optional Courses:** devops, postman  

---

## Study Flow

### 1. Python QA & Selenium Automation

#### 1.1. Module 1 — PyTest & Selenium Setup
1. **Automation Foundations**
    - Setting up PyTest, Virtual Envs, and Selenium 4 WebDriver
    - Browser Drivers: ChromeDriver, GeckoDriver, and Selenium Manager
    - Locators Strategy: ID, Name, XPath, CSS Selectors, Relative Locators
2. **WebDriver Operations & Dynamic Waits**
    - Implicit Waits vs Explicit Waits (WebDriverWait & ExpectedConditions)
    - Handling Alerts, Frames, Windows, and Shadow DOM Elements
    - Actions Chains: Drag-and-Drop, Mouse Hover, and Key Presses

#### 1.2. Module 2 — Page Object Model & Enterprise QA Framework
1. **Page Object Model (POM) Design**
    - Class-Based Page Objects and Base Page Abstraction
    - Fixtures in PyTest (Conftest.py, Scope, Autouse)
    - Data-Driven Testing using PyTest Parametrization and OpenPyXL / JSON
2. **Reporting, Logging & CI/CD Integration**
    - Logging with Python `logging` Module
    - Generating HTML & Allure Reports
    - Headless Browser Execution in Docker & GitHub Actions Pipeline
