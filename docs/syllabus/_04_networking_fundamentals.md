# Networking Fundamentals — Master Syllabus

**Target Role:** Cloud Engineer / Network Architect / Full Stack Developer / IoT Engineer  
**Difficulty Level:** Beginner  
**Estimated Duration:** 45 Hours  
**Prerequisites:** Computer Fundamentals  
**Required Courses:** computer-fundamentals  
**Optional Courses:** linux-administration  

---

## Study Flow

### 1. Networking Fundamentals

#### 1.1. Module 1 — Network Architecture & OSI Reference Model

1. **OSI Model & TCP/IP Protocol Suite**
    - The 7 Layers of the OSI Model: Physical to Application
    - Encapsulation and Decapsulation Lifecycle
    - TCP/IP 4-Layer Architecture vs OSI
    - Frame, Packet, Segment, and Payload Structures
2. **Physical Layer & Ethernet Technology**
    - Copper, Fiber, and Wireless Transmission Media
    - MAC Addresses and Ethernet Frame Structure
    - Switches, Bridges, and VLAN Tagging (802.1Q)
    - Address Resolution Protocol (ARP) Mechanics

#### 1.2. Module 2 — Network & Transport Layers

1. **IP Addressing & Subnetting (IPv4 & IPv6)**
    - IPv4 Classless Inter-Domain Routing (CIDR)
    - Subnet Mask Calculation and IP Range Planning
    - IPv6 Address Architecture and Neighbor Discovery
    - Network Address Translation (NAT) and Port Forwarding
2. **Transport Protocols: TCP & UDP**
    - TCP Three-Way Handshake and Four-Way Teardown
    - TCP Flow Control (Sliding Window) and Congestion Control
    - UDP Datagram Architecture & Use Cases (DNS, Video Streaming)
    - Socket Programming Fundamentals (TCP Sockets, UDP Sockets)

#### 1.3. Module 3 — Application Protocols & Web Cryptography

1. **DNS, DHCP, & Domain Infrastructure**
    - Domain Name System (DNS) Resolution Hierarchy (A, AAAA, CNAME, MX)
    - Recursive vs Iterative DNS Queries
    - DHCP Lease Mechanism (DORA Process)
2. **HTTP/1.1, HTTP/2, HTTP/3 & Web Security**
    - HTTP Methods, Headers, and Status Codes
    - Transport Layer Security (TLS 1.3) Handshake & Cryptography
    - Symmetric vs Asymmetric Encryption & PKI Certificates
    - WebSockets and Real-Time Event Streaming
