# Data Science & Analytics — Learning Path

**Target Role:** Data Scientist / Data Analyst  
**Estimated Duration:** 8–12 Months  
**Difficulty:** Beginner → Advanced  
**Prerequisites:** Basic Python, Basic Statistics

---

## Overview

This path builds data science expertise from Python programming and mathematical foundations through data analysis, visualization, machine learning, and business intelligence.
