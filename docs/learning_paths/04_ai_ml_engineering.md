# AI & Machine Learning Engineer — Learning Path

**Target Role:** ML Engineer / AI Systems Developer  
**Estimated Duration:** 12–18 Months  
**Difficulty:** Intermediate → Expert  
**Prerequisites:** Python Core, Engineering Mathematics

---

## Overview

This path builds AI/ML engineering expertise from mathematical foundations through classical ML, deep learning, computer vision, NLP, generative AI, and production MLOps deployment.
