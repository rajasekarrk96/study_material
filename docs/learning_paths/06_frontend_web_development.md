# Frontend Web Developer — Learning Path

**Target Role:** Frontend Developer / UI Engineer  
**Estimated Duration:** 6–9 Months  
**Difficulty:** Beginner → Intermediate  
**Prerequisites:** Basic Computer Literacy

---

## Overview

This path builds a complete frontend web developer, covering HTML structure, CSS styling, JavaScript interactivity, and modern React framework development.
