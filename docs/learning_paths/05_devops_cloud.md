# DevOps & Cloud Engineer — Learning Path

**Target Role:** DevOps Engineer / Site Reliability Engineer  
**Estimated Duration:** 8–12 Months  
**Difficulty:** Intermediate → Advanced  
**Prerequisites:** Linux basics, Git basics

---

## Overview

This path develops DevOps engineering skills covering Linux administration, containerization, CI/CD pipelines, infrastructure as code, and cloud-native architecture.
