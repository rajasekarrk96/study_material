## 🔄 Content Lifecycle Workflow

```
[1. Structure Seed]  --> [2. Content Draft (.md)] --> [3. User Review] --> [4. DB Migration] --> [5. Published Mark [x]]
   (Modules/Lessons)       (Save in docs/archive)      (Approval)           (Python Script)        (Update pending_content.md)
```

1. **Structure Seed**: Generate module and lesson records (`status='draft'`).
2. **Content Generation**: Generate comprehensive markdown content for each section (`overview`, `concept`, `syntax`, `example`, `pitfall`, `qa`).
3. **Markdown Archiving**: Save complete course markdown documents under `docs/courses/<slug>.md`.
4. **Database Migration**: Run direct migration script to sync markdown sections into SQLite DB and update status to `'published'`.
5. **Backlog Update**: Check off course in `pending_content.md`.
