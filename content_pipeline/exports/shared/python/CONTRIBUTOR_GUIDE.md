## Step-by-Step Workflow

### Step 1 — Read Everything First

1. `COURSE_METADATA.md`
2. `SYLLABUS.md`
3. `NOTE_TEMPLATE.md`
4. `STYLE_GUIDE.md`
5. `MISSING_NOTES.md`
6. Several existing notes to calibrate style (e.g. `curriculum/01-setup-and-overview/_01_01_python_overview_and_philosophy.md`)

### Step 2 — Write Notes

For each stub file in `MISSING_NOTES.md`:

1. Open the file. It contains only a title (`#` heading) and metadata blockquote with empty sections.
2. Fill in the content following `NOTE_TEMPLATE.md`.
3. Match the depth and tone of existing notes.
4. Validate against `STYLE_GUIDE.md`.

### Step 3 — Self Review

After completing all stubs:

1. Check every item in `CHECKLIST.md`.
2. Fix any issues found.
3. Fill in `REPORT.md`.

### Step 4 — Return

Return the entire `python/` folder with all stub files completed.
