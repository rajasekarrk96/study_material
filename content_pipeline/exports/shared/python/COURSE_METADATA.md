## Description

Python Programming is a comprehensive course covering the Python language from
fundamentals through advanced patterns. It is structured as a progression from
beginner setup through professional-grade Python engineering.

**Part 1 — Core Python** covers: environment setup, variables, control flow,
collections, functions, object-oriented programming, exceptions, file I/O,
concurrency basics, scientific Python, and testing.

**Part 2 — Advanced Python** covers: Python internals (object model, bytecode, GIL),
advanced OOP (MRO, ABCs, descriptors, metaclasses), functional programming,
decorators, generators, advanced concurrency, professional tooling, packaging,
and design patterns.

## Learning Outcomes

Upon completing this course, the learner will be able to:

1. Set up a professional Python development environment with virtual environments and modern tooling (`uv`, `pyproject.toml`).
2. Explain how CPython executes code, manages memory, and handles the GIL.
3. Use all Python built-in data types and collection types fluently.
4. Write clean control flow using conditions, loops, and structural pattern matching.
5. Build functions using all parameter types including `*args`, `**kwargs`, and closures.
6. Apply functional programming patterns: `map`, `filter`, `functools`, comprehensions.
7. Write closures, parametrized decorators, and class-based decorators.
8. Use generators and the full `itertools` / `functools` toolkits.
9. Design class hierarchies using single and multiple inheritance, MRO, and mixins.
10. Implement protocols, ABCs, descriptors, properties, and metaclasses.
11. Handle exceptions properly with custom exception hierarchies.
12. Use context managers (`with` statement) and `contextlib`.
13. Read and write files, CSV, JSON, YAML, and TOML.
14. Write regular expressions for text processing.
15. Organize code as modules and packages with proper import resolution.
16. Write async code with `asyncio`, `async/await`, and task groups.
17. Apply threading, multiprocessing, `concurrent.futures`, and GIL-aware design.
18. Use NumPy, Pandas, and Matplotlib for scientific computing.
19. Write unit tests with `pytest`, fixtures, mocking, and coverage.
20. Profile and debug Python programs using `pdb`, `cProfile`, and memory tools.
21. Apply creational, structural, and behavioral design patterns in Python.
22. Refactor legacy code and apply clean architecture principles.
23. Package and publish Python projects to PyPI.
