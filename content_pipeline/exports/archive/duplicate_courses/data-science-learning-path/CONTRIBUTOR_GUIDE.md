# Contributor Guide

> Read this entirely before writing a single note.

---

## Your Assignment

You are filling in stub lesson files for the **Data Science & Analytics** Learning Path.

This is a large package. The suggested approach is to work course by course, starting with Machine Learning.

---

## What You Must NOT Do

- Modify any file in SYLLABUS/
- Modify existing notes (files > 500 bytes)
- Add files not listed in REPORTS/MISSING_NOTES.md
- Rename any file or folder
- Copy or duplicate any referenced course

---

## What You Must Do

- Write notes into stub files following NOTE_TEMPLATE.md
- Follow STYLE_GUIDE.md for all formatting
- Calibrate depth against existing notes in CURRICULUM/data-analytics/ and CURRICULUM/power-bi/
- Complete CHECKLIST.md before returning
- Fill REPORT.md before returning

---

## Workflow

1. Read LEARNING_PATH.md — understand the full path
2. Read REFERENCED_COURSES.md — understand what not to duplicate
3. Open REPORTS/MISSING_NOTES.md — find your stubs
4. For each stub: open the matching SYLLABUS/<course>.md section
5. Write the note following NOTE_TEMPLATE.md
6. Check style against STYLE_GUIDE.md
7. After all stubs: complete CHECKLIST.md and REPORT.md
8. Return the full package
