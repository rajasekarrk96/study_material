# Technologies Tier (`exports/technologies/`)

_Learning OS v2 — Tier 2: Standalone Tools, Frameworks, Platforms & Protocols_

---

## 1. Definition & Core Rules

A Technology course provides standalone, deep-dive mastery of a single framework, tool, platform, library, database engine, or protocol.

### Cardinal Rules:
1. **One Technology = One Canonical Course:** Teaches ONE technology completely from setup to production patterns.
2. **Multi-Language Binding Parity:** Unified under one course (e.g. `selenium` teaches both Python and Java bindings).
3. **Canonical Singularity:** Each technology exists exactly once across the repository.
4. **No Monolithic Bundling:** Does not bundle multiple separate courses into one file.
