# Curriculum: AWS Cloud Computing

## Course Overview
- **Course Name:** AWS Cloud Computing
- **Course Description:** An introductory course on AWS Cloud Computing, covering cloud computing fundamentals, identity & security, compute, storage, networking, databases, containers, DevOps, monitoring, messaging, IoT, AI/ML, analytics, cost optimization, architecture, and industry capstone projects.
- **Learning Paths:**
  - Cloud Computing & Infrastructure
  - DevOps & SRE Engineering
  - Python Full Stack Engineering
  - IoT Full Stack Engineering
  - AI Engineering
- **Estimated Hours:** 80 Hours
- **Module Count:** 16
- **Lesson Count:** 71
- **Topic Count:** 350+
- **Curriculum Status:** READY_FOR_AUTHORING
