# Learning Paths Tier (`exports/learning_paths/`)

_Learning OS v2 — Tier 4: Career Progression Roadmaps & Milestone Sequences_

---

## 1. Definition & Core Rules

Learning Paths assemble Foundations, Technologies, and Specializations into linear, milestone-driven progressions for career tracks.

### Cardinal Rules:
1. **Zero Teaching Content:** Learning Paths contain **NO syllabuses**, **NO lesson markdown files**, and **NO notes**.
2. **Reference Only:** They contain strictly roadmap metadata (`referenced_courses.md`, `roadmap.md`), course sequences, and career milestone definitions.
3. **Decoupled Architecture:** Updating a canonical course automatically updates all referencing Learning Paths.
