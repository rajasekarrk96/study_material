## Learning Outcomes

### HTML5 Essentials
- Build semantically correct, accessible web pages
- Use modern HTML5 APIs (Canvas, Web Storage, Drag & Drop, WebSockets)
- Write valid, standards-compliant HTML5 markup

### CSS3 Styling
- Apply modern CSS layout systems (Flexbox, CSS Grid)
- Write maintainable CSS architecture (BEM, custom properties)
- Implement responsive design and CSS animations

### Bootstrap Framework
- Build responsive layouts using the Bootstrap 12-column grid
- Use Bootstrap components (navbar, cards, modals, forms)
- Customize Bootstrap using Sass variables and utility API

### JavaScript Core
- Understand the JavaScript engine, event loop, and execution model
- Write asynchronous code using Promises, async/await
- Work with DOM APIs, Fetch API, Web Storage, and Web Workers
- Apply object-oriented and functional programming patterns

### jQuery Library
- Select and manipulate DOM elements efficiently
- Handle events, animations, and AJAX using jQuery
- Understand when to use jQuery vs modern Vanilla JS

### React.js Frontend
- Build component-based UIs using functional components and hooks
- Manage state with useState, useEffect, useContext, useReducer
- Implement client-side routing with React Router v6
- Fetch data, handle async UI states, and optimize performance
- Test components with Vitest and React Testing Library
- Deploy production React apps to Nginx and Vercel
