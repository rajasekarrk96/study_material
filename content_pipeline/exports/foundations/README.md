# Foundations Tier (`exports/foundations/`)

_Learning OS v2 — Tier 1: First-Principles Zero-Prerequisite Curricula_

---

## 1. Definition & Core Rules

Foundations teach first-principles programming languages, operating systems, hardware baselines, and mathematics. 

### Cardinal Rules:
1. **Zero Prior Knowledge:** A student can open any Foundation course on Day 1 without prior knowledge.
2. **No Upstream Dependencies:** A Foundation must NOT depend on any Technology or Specialization. It may depend only on another Foundation where pedagogically necessary (e.g. `python-dsa` depends on `core-python`).
3. **No Framework Contamination:** Does not teach proprietary frameworks, cloud providers, or high-level abstractions.
