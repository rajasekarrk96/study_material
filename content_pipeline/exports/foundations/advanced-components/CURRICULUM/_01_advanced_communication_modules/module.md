# Advanced Communication Modules

Module Number: 1
Estimated Lessons: 3
Estimated Duration: 3.75 Hours

## Module Learning Objectives
By the end of this module, students will be able to:
- Select the appropriate wireless technology (Bluetooth, Wi-Fi, or long-range radio) for a given IoT requirement.
- Wire and configure Bluetooth (HC-05/HC-06, ESP32) modules and exchange serial data.
- Connect an ESP8266/ESP32 to Wi-Fi in STA and AP modes and serve/consume HTTP, TCP, and UDP.
- Compare and use long-range technologies (LoRa, ZigBee, nRF24L01, RF433) and understand mesh networking.
- Apply correct voltage levels, decoupling, and best practices for reliable wireless links.
