# Curriculum: Electronics Simulation using Proteus & Wokwi

## Course Overview
- **Course Name:** Electronics Simulation using Proteus & Wokwi
- **Course Description:** An intermediate technology course on Electronics Simulation using Proteus & Wokwi, covering simulation fundamentals, circuit creation, microcontrollers (Arduino, ESP32) simulation, communication interfaces, displays, virtual instruments, and verification projects.
- **Category:** Technology Course
- **Learning Paths:**
  - IoT Full Stack Engineering
  - Embedded Systems Engineering
  - Electronics & PCB Design
  - Robotics Engineering
- **Estimated Hours:** 40 Hours
- **Total Modules:** 10
- **Total Lessons:** 34
- **Total Topics:** 180+
- **Curriculum Status:** READY_FOR_AUTHORING
