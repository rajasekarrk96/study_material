# Curriculum: ESP32 Development

## Course Overview
- **Course Name:** ESP32 Development
- **Course Description:** A technology course on ESP32 Development, covering ESP32 fundamentals, GPIO programming, communication interfaces, WiFi/Bluetooth, IoT protocols, sensor integration, display/storage, ESP32-CAM Edge AI, FreeRTOS multitasking, debugging, and industry IoT projects.
- **Category:** Technology Course
- **Learning Paths:**
  - IoT Full Stack Engineering
  - Embedded Systems Engineering
  - Robotics Engineering
  - Edge AI & TinyML
- **Estimated Hours:** 80 Hours
- **Total Modules:** 12
- **Total Lessons:** 43
- **Total Topics:** 280+
- **Curriculum Status:** READY_FOR_AUTHORING
