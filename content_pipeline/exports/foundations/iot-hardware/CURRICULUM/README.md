# Curriculum: IoT Hardware Engineering

## Course Overview
- **Course Name:** IoT Hardware Engineering
- **Course Description:** A technology course on IoT Hardware Engineering, covering IoT hardware fundamentals, microcontroller platforms, communication hardware, sensor/actuator systems, displays, power electronics, PCB design, debugging, and industrial applications.
- **Category:** Technology Course
- **Learning Paths:**
  - IoT Full Stack Engineering
  - Embedded Systems Engineering
  - Electronics & PCB Design
  - Robotics Engineering
- **Estimated Hours:** 120 Hours
- **Total Modules:** 12
- **Total Lessons:** 41
- **Total Topics:** 320+
- **Curriculum Status:** READY_FOR_AUTHORING
