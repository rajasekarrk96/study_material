# Curriculum: IoT Projects

## Course Overview
- **Course Name:** IoT Projects
- **Course Description:** A project-based course on IoT Projects, covering project planning, hardware design, embedded programming, backend & cloud integration, dashboard development, AI/automation, deployment, testing, and industry capstones.
- **Category:** Project Course
- **Learning Paths:**
  - IoT Full Stack Engineering
  - Embedded Systems Engineering
  - AI Engineering
  - Data Science & Analytics
  - Robotics Engineering
- **Estimated Hours:** 120 Hours
- **Total Modules:** 12
- **Total Lessons:** 46
- **Total Topics:** 350+
- **Curriculum Status:** READY_FOR_AUTHORING
