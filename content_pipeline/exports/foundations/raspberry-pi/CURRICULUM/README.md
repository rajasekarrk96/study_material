# Curriculum: Raspberry Pi Development

## Course Overview
- **Course Name:** Raspberry Pi Development
- **Course Description:** An intermediate technology course on Raspberry Pi Development, covering hardware components, Raspberry Pi OS, Linux environment, GPIO programming, hardware interfacing, communication protocols, IoT connectivity, camera integration, edge AI, and industrial automation projects.
- **Category:** Technology Course
- **Learning Paths:**
  - IoT Full Stack Engineering
  - Embedded Systems Engineering
  - AI & Edge Computing
  - Robotics Engineering
  - Computer Vision Engineering
- **Estimated Hours:** 80 Hours
- **Total Modules:** 10
- **Total Lessons:** 35
- **Total Topics:** 220+
- **Curriculum Status:** READY_FOR_AUTHORING
