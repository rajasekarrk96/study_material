# Curriculum: Data Structures & Algorithms in Python

## Course Overview
- **Course Name:** Data Structures & Algorithms in Python
- **Course Description:** An enterprise-grade technology course on Data Structures & Algorithms in Python, covering algorithm analysis, linear and non-linear data structures, sorting/searching, heaps, graphs, greedy algorithms, dynamic programming, advanced data structures, problem solving patterns, and interview preparation.
- **Category:** Foundation Course
- **Learning Paths:**
  - Python Full Stack
  - AI & Machine Learning
  - Data Science
  - Competitive Programming
  - Interview Preparation
  - Software Engineering
- **Estimated Hours:** 80 Hours
- **Total Modules:** 15
- **Total Lessons:** 74
- **Total Topics:** 300+
- **Curriculum Status:** READY_FOR_AUTHORING
