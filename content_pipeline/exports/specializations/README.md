# Specializations Tier (`exports/specializations/`)

_Learning OS v2 — Tier 3: Professional Domain Integrations & Capstones_

---

## 1. Definition & Core Rules

Specializations combine multiple prerequisite Foundations and Technologies into an integrated domain workflow. They teach **system integration, architecture, cross-technology pipelines, and production engineering trade-offs**.

### Cardinal Rules:
1. **Never Reteach Prerequisites:** Specializations assume complete mastery of prerequisite foundations and technologies.
2. **Integration Focus:** The core curriculum consists of cross-technology workflows (e.g. streaming camera feeds to deep learning models and publishing inference events via MQTT).
3. **Capstone-Driven:** Culminates in production-grade integration projects.
