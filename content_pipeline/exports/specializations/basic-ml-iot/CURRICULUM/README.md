# Curriculum: Basic Machine Learning for IoT

## Course Overview
- **Course Name:** Basic Machine Learning for IoT
- **Course Description:** An introductory course on Machine Learning for IoT, covering ML fundamentals, data preparation, supervised/unsupervised learning, model evaluation, TinyML & Edge AI, Computer Vision, predictive applications, deployment, and industry capstone projects.
- **Category:** Technology Course
- **Learning Paths:**
  - IoT Full Stack Engineering
  - AI Engineering
  - Data Science & Analytics
  - Embedded Systems Engineering
- **Estimated Hours:** 60 Hours
- **Total Modules:** 10
- **Total Lessons:** 39
- **Total Topics:** 220+
- **Curriculum Status:** READY_FOR_AUTHORING
